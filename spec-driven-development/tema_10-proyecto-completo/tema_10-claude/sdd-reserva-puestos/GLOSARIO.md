# Glosario del dominio

| Término | Definición |
| --- | --- |
| Oficina | Sede física de la empresa. Se identifica por un código (MAD-C, MAD-N, BCN). |
| Sala | Espacio dentro de una oficina que contiene puestos. Ejemplo: "Sala Turing". |
| Puesto | Posición física con mesa, silla y ordenador. Código único: OFICINA-SALA-NN (p. ej., MAD-C-TUR-05). |
| Equipamiento | Características adicionales del puesto: monitor estándar, ultrawide, doble pantalla, dock station. |
| Reserva | Asignación de un puesto a un empleado para una fecha y franja concreta. |
| Franja horaria | Bloque reservable: mañana (08:00-14:00), tarde (14:00-20:00), día completo (08:00-20:00). |
| Check-in | Confirmación presencial del empleado al llegar al puesto reservado. |
| Liberación automática | Cancelación por el sistema si no hay check-in en 30 minutos desde el inicio de la franja. |
| Bloqueo | Estado de un puesto que impide su reserva (mantenimiento, avería). Lo gestiona Facilities. |
| No-show | Reserva sin check-in ni cancelación previa. |
| Empleado | Usuario que reserva puestos. Autenticado vía Azure AD. |
| Responsable de equipo | Empleado con permiso adicional para reservar en nombre de miembros de su equipo. |
| Administrador Facilities | Usuario que gestiona oficinas, salas, puestos, bloqueos e informes. |
